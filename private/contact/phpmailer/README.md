# PHPMailer 7.1.1

Unmodified SMTP classes from the official [PHPMailer v7.1.1 release](https://github.com/PHPMailer/PHPMailer/releases/tag/v7.1.1).
Only `Exception.php`, `PHPMailer.php`, `SMTP.php`, and `LICENSE` are included.
They are loaded directly as described in the upstream manual, so Composer is not needed on XServer.
